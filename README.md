## SuidaQuest Админ-панель
![image](https://github.com/user-attachments/assets/8ef683e4-4c33-4d42-b20a-078d14e3716f)
SuidaQuest Админ-панель - часть веб-приложения SuidaQuest, предназначенная для добавления, изменения и удаления квестов администраторами сервиса
## Функционал
1. Создание сюжетных квестов
2. Создание образовательных тестов
3. Экраны с вариантами ответов / свободным ответом
4. Добавление видеоматериалов
5. Добавление аудиоматериалов
6. Добавление изображений
## Зависимости

2. "express": "^4.19.2",
3. "hbs": "^4.2.0",
4. nodemon": "^3.1.4",
5. "request": "^2.88.2",
6. "requests": "^0.3.0"
## Структура проекта
1. public - статика (css/downloads/resources)
2. views - представления handlebars
3. index.js - сервер
